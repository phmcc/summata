# Significant digits to which wilcox.test() rounds before ranking

Significant digits to which wilcox.test() rounds before ranking

## Usage

``` r
wilcox_digits_rank()
```

## Value

The default of the `digits.rank` argument of
[`stats::wilcox.test()`](https://rdrr.io/r/stats/wilcox.test.html), or
`Inf` where it has none.
