# Name the coefficients of the levels of a model's factors

The coefficient of a factor level is named by the variable followed by
the level (*e.g.,* "sexMale").

## Usage

``` r
level_terms(xlevels)
```

## Arguments

- xlevels:

  Named list of factor levels, or `NULL`.

## Value

Character vector of the names that the coefficients of the levels in
`xlevels` take.
